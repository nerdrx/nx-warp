# 90 Hz benchmark gallery

These figures are regenerated by [`generate_gallery.py`](generate_gallery.py),
which reads the archived CSVs directly. Each plot describes native padded
stereo (4352 × 2176), synthetic camera motion at 90 Hz, and offscreen parser,
upload, and approximate PLANAR rendering on Pico 4. The measurements exclude
PC encoding, network, compositor, display scanout, and physical pose input.
An interval is a scheduling interval; it is not latency.

## Graphs

![Latency ECDF](01-latency-ecdf.png)

Empirical completion-time distributions for the six single-pass arms, with the
11.111 ms 90 Hz deadline as a reference.

![Single versus full time series](02-single-vs-full-timeseries.png)

Per-frame completion traces for the paired single-pass and full-draw arms.

![Stage components](03-stage-components.png)

Median and p99 measured parse, upload, and GPU execution components. Fence wait
is omitted because it overlaps GPU execution and adding both would double-count
wall time.

![Deadline misses](04-deadline-misses.png)

Exact integer counts of frames above 11.111 ms for the six final comparison arms.

![Skipped tiles and age](05-skips-and-age.png)

Per-frame skipped-tile fraction and oldest retained tile age for single-pass and
multi-pass arms.

![Historical starvation](06-historical-v1-v2-starvation.png)

Historical v1 lifetime-maximum, v1 forced-2 ms, and v2 expiring-estimate traces.
These controls document starvation behavior and are not production claims.

![Budget pressure](07-budget-pressure-age.png)

Artificial 2 ms and 3 ms admission-budget pressure controls. The 90 Hz
deadline is not used as the budget threshold in this figure.

Regenerate from the repository root with:

```sh
python3 docs/visual-results/generate_gallery.py
```

The separate archives keep final paired runs, historical scheduler controls,
and new artificial-pressure tests distinct. Run labels can repeat across
archives, so they must never be merged by name alone.
