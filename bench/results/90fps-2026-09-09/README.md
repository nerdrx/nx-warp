# 90 fps investigation archive

The [compact-centre](compact-centre/README.md) experiment records the fixed
axis 512-centre presentation map and archived decoder evidence. See the
[mapping schematic](compact-centre/compact-centre-map.png) and
[timing plot](compact-centre/timing-comparison.png). The packed compact result
is an 8.23 ms decoder-only p50 in that archive versus 11.10 ms for native;
this is not a live 90-fps or motion-to-photon result.
