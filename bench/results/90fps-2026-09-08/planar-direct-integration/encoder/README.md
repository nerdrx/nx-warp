# Native image encoder check

This is a short three-frame API check on the PC, not a sustained live-stream benchmark.
Input is 4352 × 2176 side-by-side stereo, generated by
`probe/planar-direct/make-camera-fixture.py`: poses at source frames 0, 19 and 75,
90 Hz. Encode options: `--eyes 2 --inter --planar-gpu-flat --image --frames 3`,
QP 26, with `NXE_TIME=1` for stage timing.

The baseline averaged 25.034 ms. The final optimized run averaged 3.290 ms,
maximum 3.357 ms. See the raw logs alongside this file. The optimization omits
reference pixel reconstruction, unused coefficient readback and entropy-table
selection/training only for complete GPU-flat frames with atlas disabled.
Incompatible later frames are rejected rather than using an unwritten reference.

All 6,936 tiles across the three frames were PLANAR. The serialized streams differ
because unused entropy metadata changes; both decode to exactly the same
42,614,784 YUV bytes, SHA-256
`37c7c9e2e85bb4a997f029c9cf07ae211236a44bada41cb206f91022f51fe4b1`.
File identities are in `files.json`. The negative API check rejects GPU-flat
without INTER.

These timings exclude networking and Pico presentation. A longer workload and
live measurements are required before interpreting the speedup as delivered FPS.
