# Independent ASTC delivery / recovery audit

Source: `wt-pyrowave-probe` at `2f53c2cb`; source-only, no builds or runtime activity.

Independent ASTC packet decoding does not currently mean out-of-order frame delivery. `shard_accumulator` uses the six-frame/three-skew `frame_window` (`client/decoder/shard_accumulator.h:58–60`); `pump()` visits only its oldest slot (`shard_accumulator.cpp:224–237`), and `try_submit_front()` calls `frame_completed()` only after contiguous shards plus the terminal timing marker are present (`:410–475`). A complete successor waits until the skew rule or window bound retires a preceding incomplete frame. The Android skew and age-deadline relaxations are default-off and already covered as frame-window/helper tests (`shard_accumulator.cpp:49–70`; `docs/ASTC_REASSEMBLY_TRIAL.md`; `tests/accumulator_test.cpp:568–601`). This is a known freshness tradeoff, not a newly justified policy change.

The actual NACK path is stronger than the prior unknown-tail replay’s modeled adapter: `stream_network.cpp:58–88` computes the recovery-poll timeout, then invokes each NXASTC accumulator’s `poll_nacks`; `shard_accumulator::try_nack()` builds/sends a real NACK from actual `shard_set::missing_shards()` after parity drain (`client/decoder/shard_accumulator.cpp:300–380`). Polling is opt-in (`WIVRN_NX_RECOVERY_POLL=1` host / Android property, read once at thread start); ordinary per-arrival NACK checks remain at `push_shard`/`push_parity` (`:168–218`). Quiet polling adds no new NACK policy, and unknown newest-frame tails remain unrequested when there is no end marker. See `docs/ASTC_RECOVERY_POLL.md` and `continuous/unknown-tail-arrival/README.md` for the prior helper/replay limits.

**No new production change is justified.** The concrete remaining evidence gap is one CPU integration gate for the existing opt-in recovery path: drive real `shard_accumulator::push_shard`/`push_parity`, `next_nack_deadline`, `poll_nacks` and the actual NACK callback using a fake decoder/clock/scene. Start with one older frame containing a confirmed interior hole and no later arrivals; assert the two quiet-gated rounds and eventual completion after repair. Also assert incomplete unknown newest-tail and parity-repairable holes send no NACK. This specifically tests the `stream_network` timeout-to-accumulator adapter that the prior replay did not execute; it does not test the Android property, a real socket, RF arrival distribution, power, or user-visible latency. Keep all recovery properties off until live evidence warrants activation.
