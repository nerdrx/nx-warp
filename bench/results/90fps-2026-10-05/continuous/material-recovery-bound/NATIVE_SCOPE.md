# Native ASTC controller-scope audit

At source `6902940f`, native ASTC `encode()` returns ordinary `video_encoder::data` ([video_encoder_astc.cpp](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/encoder/video_encoder_astc.cpp), lines 302–307, 550). The shared sender passes its byte span to `SendData` ([video_encoder.cpp](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/encoder/video_encoder.cpp), lines 95–122); frame completion calls `on_frame_sent(frame, stream, bytes)` with no quality metadata (lines 1082–90). The session forwards the default zero budget/period ([wivrn_session.cpp](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/driver/wivrn_session.cpp), lines 1005–10; controller declaration defaults at [bitrate_controller.h](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/driver/bitrate_controller.h), line 448).

Thus native ASTC does not enter direct quality mode from its local q0–q6 byte controller. `on_frame_bytes` sets the measured-stream bit but clears that stream's quality bit when budget is zero ([bitrate_controller.cpp](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/driver/bitrate_controller.cpp), lines 496–538). The classifier requires both masks equal `1` ([same](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/driver/bitrate_controller.cpp), line 1112); two untagged eye streams yield measured mask `3`, quality mask `0`. If BBR is active, ASTC therefore uses generic BBR slowdown/estimation; with AIMD it uses AIMD. BBR is not guaranteed: AIMD is the source default ([bitrate_controller.h](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/driver/bitrate_controller.h), lines 179–188), server `bitrate-auto.mode` can select BBR ([configuration.cpp](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/driver/configuration.cpp), lines 237–248), and explicit client selection overrides it (controller cpp, lines 99–104; session cpp, line 143).

ASTC requires one eye per encoder and logs its dynamic extent ([ASTC cpp](https://github.com/nerdrx/wivrn-nx/blob/6902940fcd1cb15cef2337e9d6ab85cc266ebbd4/server/encoder/video_encoder_astc.cpp), lines 136–142); 2176² is a profile/fixture size, not a hardcoded or verified live-session extent. NX Warp's `SendPacket` path explicitly carries quality budget/period (video_encoder.cpp, lines 1122–23, 1171–75), unlike ASTC's `SendData` route. Untagged virtual BBR tests exercise the generic branch, but do not establish the user's current control-law selection, active extent, or runtime benefit.
